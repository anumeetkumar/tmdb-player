Developer Integration Guide

VidNest provides an easy, zero-setup HLS streaming embed interface. Integrate it in seconds.

HTML Iframe Embed API

To embed movies or episodes seamlessly in your streaming portal, simply load our responsive URL endpoints in an iframe element.

Routing URL format Description
https://vidnest.fun/embed/movie/{tmdb_id} Embeds a movie player matching the specified TMDB movie database identifier.
https://vidnest.fun/embed/tv/{tmdb_id}/{season}/{episode} Embeds a specific television episode player with season and episode coordinates.

Query String Options

Option Allowed Values Default Description
server prime, lamda, alfa, delta prime Specifies preferred routing server (Failovers auto-kick on fallback).
autoplay 1, 0 0 Determines whether media automatically plays and prepares feeds on load.
sub en, es, fr, none en Sets the default preloaded subtitle language on player initialization.

REST JSON Stream Resolvers

For professional platforms building fully custom players, fetch the direct adaptive HLS `.m3u8` feeds using our REST endpoint.

HTTP Request Method
GET https://api.vidnest.fun/v2/stream/resolve?type=tv&id=273240&s=1&e=1&key=YOUR_API_KEY

Smart Failovers & Ad-Block Core

VidNest is engineered for zero-downtime streaming. Even if our master HLS feeds face network blocks, our engines protect continuity.

Resilient Active Routing

Our player checks the selected server stream integrity in real-time. If buffering stalls or a server fails to resolve for over 3 seconds, it silently migrates the client stream to the next fastest responsive CDN pipeline.

Zero Pop-up Sandbox Core

Every server integration strips third-party ad tags, redirect triggers, and pop-up loaders. When embedded, our iframe sandbox restricts frame redirects so your users never face malicious ad spam.
